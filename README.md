# API CRUD de Usuários

Projeto desenvolvido em Python utilizando Flask para criação de uma API REST com operações CRUD.

##  Tecnologias utilizadas
- Python
- Flask
- SQLite

## Funcionalidades
- Criar usuário
- Listar usuários
- Buscar por ID
- Atualizar usuário
- Deletar usuário

##  Como executar

```bash
pip install flask
python app.py
